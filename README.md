# 《自动控制原理》AI 智慧课程平台

沈阳工业大学人工智能学院《自动控制原理》智慧课程全栈系统：课程主页 + 在线仿真实验平台 + 智慧课堂教学工具箱，开箱即用、数据本地化，可直接部署到教室电脑或校园服务器。

## 功能总览

### 🏠 课程主页 `/`
课程亮点、章节大纲（8 章 / 85 知识点 / 100 题库）、AI 助教答疑、仿真实验入口、学习资源、师资团队、学习排行榜。

### 🔬 在线仿真实验平台 `/lab`
10 个覆盖全书知识脉络的交互实验，浏览器即开即用，无需安装 MATLAB：

| 实验 | 章节 | 亮点 |
|---|---|---|
| 一阶系统时域响应 | 第二章 | RC 充电电路动画、电子流、63.2% 标注 |
| 二阶系统阶跃响应 | 第三章 | 质量-弹簧-阻尼机构动画 + 四大动态指标 |
| 极点位置与响应形态 | 第三章 | **可直接拖拽** s 平面极点，实时看响应 |
| 伯德图频域分析 | 第五章 | 渐近线、稳定裕度、扫频点分环节计算流程 |
| 奈奎斯特图与稳定判据 | 第五章 | 扫频动画、包围圈、Z=P−2N 判定流程 |
| 根轨迹绘制与分析 | 第四章 | 数值解特征方程，K 增益自动扫掠动画 |
| PID 控制器整定 | 第六章 | P/I/D 三分量分解、Z-N 一键整定、抗饱和、负载扰动 |
| 系统型别与稳态误差 | 第三章 | 型别×输入交叉验证、ess 速查表 |
| 非线性系统相平面 | 第七章 | 相轨迹动画、极限环判别、四种非线性 |
| 采样与数字控制 | 第八章 | ZOH 离散化、z 平面稳定性圆、连续/离散对比 |

每个实验均含：**动画演示**（机构简图 / 光点扫掠 / 轨迹拖尾）、**逐步计算流程面板**（公式 → 代入 → 结果，随参数实时更新）、实验原理 / 步骤 / 思考题，实验参数与指标可一键保存到本地数据库。

核心仿真引擎（`src/utils/labsim.ts`）为纯 TypeScript 实现：Durand-Kerner 多项式求根、RK4 状态空间仿真、PID 闭环（抗积分饱和）、伯德/奈奎斯特数据、根轨迹分支追踪与分离点、Ziegler-Nichols 整定、ZOH 离散化（矩阵指数 + Faddeev–LeVerrier），全部输出已与教科书理论值交叉验证。

### 📡 智慧课堂教师控制台 `/classroom`
面向课堂大屏（投影）设计的 8 个模块，全部数据实时存入本地 SQLite：

- **智能签到**：生成二维码 + 6 位加入码，学生手机扫码签到；实时到课率、缺席名单（需导入花名册）、**签到姓名词云**、随机摇号抽问、CSV 导出
- **课堂答题**：单选/判断/简答，实时作答柱状图、正确率、一键公布答案、简答题**答案词云**
- **投票表决**：2~6 选项实时比例条
- **弹幕提问墙**：学生扫码发弹幕，投屏模式大屏滚动 + 关键词词云
- **难度反馈**：下课一键评价难度，实时直方图
- **课堂计时器**：全屏倒计时（讨论/练习）
- **随机分组**：名单洗牌动画均分小组
- **历史与导出**：往期数据复盘、CSV 导出、支持"继续监控"恢复进行中的会话

### 📱 学生端 `/join`
手机扫码直达（或输入 6 位加入码），免登录参与签到/答题/投票/弹幕/评价，身份信息自动记忆。

## 快速开始

```bash
npm install          # 安装依赖
npm run seed         # 初始化演示数据（可选）

# 开发模式（前端 5173 + 后端 4000，二维码走局域网）
npm run dev:fullstack

# 生产模式（单端口 4000，前后端一体）
npm run deploy:prepare   # 构建前端 + 后端
npm start                # http://localhost:4000，局域网内手机可直接扫码访问
```

生产部署：`NODE_ENV=production node dist-server/api/index.js`，默认监听 `0.0.0.0:4000`（可用 `.env` 中 `PORT` 修改）。上课时教师浏览器打开 `http://<教师机IP>:4000/classroom`，学生微信/浏览器扫码即可，无需安装任何 App。

## 数据与存储

- 本地 SQLite：`data/app.db`（WAL 模式），涵盖用户、进度、答题、实验记录、AI 会话、**全部课堂互动数据**，拷贝该文件即完成备份迁移
- 所有互动接口均经 zod 校验；签到按学号去重；正确答案永不下发学生端
- 演示账号：`teacher / teacher123`（教师）、`student1 / student123456`（学生），详见 `npm run seed`
