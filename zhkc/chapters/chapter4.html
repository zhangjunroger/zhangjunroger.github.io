卷积神经网络

本章系统介绍卷积神经网络（CNN）的核心组件：卷积层、池化层、Padding 与 Stride、感受野的概念，以及经典架构 LeNet / AlexNet / VGG / GoogLeNet / ResNet / EfficientNet 的设计思想。读者将能够从零实现一个卷积层，并能读懂主流 CNN 架构。

4.1 为什么需要卷积

将一张 $224 \times 224$ 的 RGB 图像展平为一个 15 万维的向量直接送给 MLP，会立刻遇到两个难题：

  • 参数量爆炸：第一层若有 1024 个神经元，参数达 $150{,}528 \times 1024 \approx 1.5$ 亿；
  • 丢失空间结构信息：MLP 对像素的排列顺序是完全不敏感的——若把一张图的所有像素随机打乱再喂给同一个 MLP，输出结果会非常不同。

卷积神经网络利用了自然图像的两个先验：

  1. 局部相关性：图像中的某个像素主要与其相邻的几个像素强相关；
  2. 平移不变性："猫的耳朵"出现在图像左上角或右上角都仍然是"猫的耳朵"，同样的特征检测子可以在整幅图上被复用。

4.2 卷积的数学定义

严格来说，深度学习中的"卷积"其实是 互相关（Cross-Correlation），与信号处理中的卷积相比缺了一个核翻转。

设输入矩阵 $\boldsymbol{X} \in \mathbb{R}^{H \times W}$，卷积核（滤波器）$\boldsymbol{K} \in \mathbb{R}^{k \times k}$。输出特征图 $Y \in \mathbb{R}^{(H-k+1) \times (W-k+1)}$ 的元素为：

$$ Y_{i,j} = \sum_{p=0}^{k-1} \sum_{q=0}^{k-1} X_{i+p,\,j+q} \cdot K_{p,\,q}. \tag{4.1} $$

在真实实现中，每个卷积核还带有一个标量偏置 $b$，并且会对整个 mini-batch、多通道同时并行计算。

4.3 Padding、Stride 与输出尺寸

  • Padding：在输入的四周填充 $p$ 行/列零值（或其他值），用来避免边缘信息损失、控制输出尺寸；
  • Stride：滤波器每次滑动的步长 $s$。$s=1$ 即 dense convolution；$s>1$ 同时起到下采样作用。

给定输入尺寸 $H_{\text{in}} \times W_{\text{in}}$，卷积核大小 $k$，填充 $p$，步长 $s$。输出尺寸为：

$$ H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2p - k}{s} \right\rfloor + 1, \qquad W_{\text{out}} = \left\lfloor \frac{W_{\text{in}} + 2p - k}{s} \right\rfloor + 1. \tag{4.2} $$

常见的两种设计：

  • same padding：选 $p = \lfloor k/2 \rfloor$，使得当 $s=1$ 时 $H_{\text{out}} \approx H_{\text{in}}$，空间维度近似保持不变；
  • valid padding：$p = 0$，即不填充，输出必小于输入。

输入 $32 \times 32$，卷积核 $3 \times 3$，$p=1$，$s=1$。输出 = $\lfloor(32+2-3)/1\rfloor+1 = 32$。保持空间尺寸不变。

若 $s=2$，$p=1$，$k=3$，则输出 = $\lfloor(32+2-3)/2\rfloor+1 = \lfloor 31/2 \rfloor+1 = 16$。

4.4 多输入通道、多输出通道、1×1 卷积

一幅 RGB 图像有 3 个通道。一般地，记输入通道数为 $C_{\text{in}}$，输出通道数为 $C_{\text{out}}$。

  • 对每个输出通道 $c \in \{1,\dots,C_{\text{out}}\}$，使用一个卷积核张量 $\boldsymbol{K}_c \in \mathbb{R}^{C_{\text{in}} \times k \times k}$（即对每个输入通道使用一个二维核并求和）；
  • 输出通道 $c$ 的特征图为 $\boldsymbol{Y}_c = \sum_{d=1}^{C_{\text{in}}} \boldsymbol{X}_d \star \boldsymbol{K}_{c,d} + b_c$，其中 $\star$ 表示二维互相关；
  • 整个卷积层的参数为 $C_{\text{out}} \times C_{\text{in}} \times k \times k + C_{\text{out}}$。

4.4.1 1×1 卷积（Network in Network / Lin et al., 2013）

当 $k=1$ 且 $s=1$，$p=0$ 时，输出空间尺寸与输入相同，但通道数可由 $C_{\text{in}}$ 被"组合"为 $C_{\text{out}}$。这等价于对每个 空间位置 独立地做一次仿射变换 + 非线性。主要用于：

  • 通道数升/降维（跨通道特征融合）；
  • 在不增加空间变换参数的前提下增加非线性；
  • 作为现代 Transformer 中 1×1 卷积替代 MLP 的灵感来源。

4.4.2 分组卷积（Grouped Convolution）

将输入通道分成 $G$ 组，每组只与自己的 $C_{\text{in}}/G$ 个通道卷积，输出通道也相应被分成 $G$ 组。参数量与计算量下降 $G$ 倍。ResNeXt、MobileNet、ShuffleNet 都大量使用分组卷积与可分离卷积来获得轻量高效模型。

4.5 池化层（Pooling）

池化层在每个局部窗口上取最大值（Max Pooling）或平均值（Average Pooling），起到以下作用：

  • 降低空间维度，减少后续层的计算量；
  • 提供一定程度的平移/旋转/缩放不变性；
  • 扩大后续层的感受野。

典型设置：$2 \times 2$ 窗口、步长 $2$，使得长宽各减半。输出尺寸公式与卷积层类似：

$$ H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2p - k}{s} \right\rfloor + 1. \tag{4.3} $$

现代 CNN 设计中，池化层越来越多被"带 stride=2 的卷积"所取代。原因：(a) 卷积可学习；(b) 能在降采样的同时融合通道信息。ResNet 的过渡层即是典型例子。

4.6 感受野（Receptive Field）

第 $\ell$ 层的某个神经元的 感受野 是指：原始输入图像中能影响该神经元输出值的区域大小。记第 $\ell$ 层的感受野大小为 $R^{(\ell)}$，该层卷积/池化的核大小为 $k^{(\ell)}$、步长为 $s^{(\ell)}$，则有递推公式：

$$ R^{(\ell)} = R^{(\ell-1)} + \big(k^{(\ell)} - 1\big) \cdot \prod_{i=1}^{\ell-1} s^{(i)}. \tag{4.4} $$

初始 $R^{(0)} = 1$，$\prod_{i=1}^{0} s^{(i)} = 1$。这个公式在设计目标检测与分割模型时非常有用：需要保证深层特征图的每个位置对应的感受野覆盖到足够大的物体。

4.7 卷积层的梯度与反向传播

考虑一个简化的单通道情况：输入 $\boldsymbol{X} \in \mathbb{R}^{H \times W}$，核 $\boldsymbol{K} \in \mathbb{R}^{k \times k}$，无 padding、stride 1，则输出 $\boldsymbol{Y} = \boldsymbol{X} \star \boldsymbol{K}$。

设上游传来的对 $Y$ 的梯度为 $\partial \ell / \partial Y_{i,j} = \delta_{i,j}$。求：

$$ \frac{\partial \ell}{\partial K_{p,q}} = \sum_{i,j} \delta_{i,j} \cdot X_{i+p,\,j+q}, \tag{4.5} $$
$$ \frac{\partial \ell}{\partial X_{u,v}} = \sum_{i,j} \delta_{i,j} \cdot K_{u-i,\,v-j}. \tag{4.6} $$

换言之，核参数的梯度 = 以 $\delta$ 为核、对 $\boldsymbol{X}$ 做互相关；输入 $\boldsymbol{X}$ 的梯度 = 以 $\delta$ 为核、对 $\boldsymbol{K}$ 做 全卷积（Full Convolution）（相当于零填充后的 cross-correlation）。这正是反卷积 / 转置卷积（Transposed Convolution）的理论基础。

4.8 经典 CNN 架构纵览

4.8.1 LeNet-5（LeCun et al., 1998）

首个在手写数字识别（MNIST）上取得成功的 CNN，奠定了"卷积-池化-非线性-全连接"的基本范式。典型结构：

  • 输入 $28 \times 28 \to \texttt{Conv}(5 \times 5, 6) \to \text{Tanh} \to \text{AvgPool}(2)$
  • $\to \texttt{Conv}(5 \times 5, 16) \to \text{Tanh} \to \text{AvgPool}(2) \to \text{FC}(120) \to \text{FC}(84) \to \text{Gaussian}(10)$

4.8.2 AlexNet（Krizhevsky et al., 2012）

ImageNet 2012 冠军，将 Top-5 错误率从传统方法的约 26% 拉低到约 15%。与 LeNet 相比主要创新点：

  • 更大更深的网络，使用 ReLU 激活（解决深层 Sigmoid 梯度消失）；
  • 使用 Dropout 防止过拟合；
  • 使用数据增强（随机裁剪、颜色抖动）；
  • 使用双 GPU 并行训练；
  • 使用 Local Response Normalization（LRN），后被 BN 取代。

4.8.3 VGG（Simonyan & Zisserman, 2014）

VGG 的核心洞察是：堆叠两个 $3 \times 3$ 卷积（带 ReLU）等价于一个 $5 \times 5$ 的有效感受野，却参数更少、非线性更多。因此整个网络都只用 $3 \times 3$ 卷积、$2 \times 2$ max-pooling，空间维度每次减半、通道数每次翻倍。

VGG-16 总层数 = 13 个卷积层 + 3 个全连接层；VGG-19 再多 3 个卷积层。

4.8.4 GoogLeNet / Inception（Szegedy et al., 2014）

核心思想是在同一层内 并行使用多种不同尺寸的卷积核（1×1, 3×3, 5×5），并通过 1×1 卷积进行瓶颈降维，再将它们的输出在通道维度拼接。这种"Inception module"以极少的参数实现了多尺度特征提取。

4.8.5 ResNet（He et al., 2016）

残差网络通过引入残差连接（Residual Connection / Skip Connection）让深层网络的训练变得容易：

$$ \boldsymbol{x}_{\ell+1} = \boldsymbol{x}_{\ell} + \mathcal{F}(\boldsymbol{x}_{\ell}; \theta_{\ell}), \tag{4.7} $$

其中 $\mathcal{F}$ 是残差分支（典型：$\text{Conv} \to \text{BN} \to \text{ReLU} \to \text{Conv} \to \text{BN}$，在与主路径相加后再过一次 ReLU）。当通道数需要增加或空间维度需要降采样时，主路径通过一个 $1 \times 1$、stride=2 的卷积来匹配尺寸。

ResNet 使训练 100 层甚至 1000 层的网络变得可行。后续的 ResNeXt、SENet、CBAM、ConvNeXt 等，均在残差基本模块上做了精细化改造。

4.8.6 MobileNet / EfficientNet

  • MobileNet（Howard et al., 2017）：使用 深度可分离卷积（Depthwise + Pointwise）显著削减参数：一个 $3 \times 3$ 卷积的计算量可以降低约 8~9 倍。
  • EfficientNet（Tan & Le, 2019）：在基础网络上同时进行 深度、宽度、分辨率 的复合缩放（Compound Scaling），配合 NAS 搜索到的基础模型，在同等精度下比之前的模型小得多也快得多。

4.9 代码实现：用 NumPy 实现 Conv2d 与 MaxPool2d

Python / NumPy 
import numpy as np

def conv2d(X: np.ndarray, K: np.ndarray, bias: np.ndarray,
             stride=1, padding=0) -> np.ndarray:
    """
    X: (C_in, H_in, W_in)
    K: (C_out, C_in, k, k)
    bias: (C_out,)
    输出: (C_out, H_out, W_out)
    """
    C_in, H_in, W_in = X.shape
    C_out, _, k, _ = K.shape
    s, p = stride, padding

    # padding
    X_pad = np.pad(X, ((0, 0), (p, p), (p, p)), mode='constant')
    H_out = (H_in + 2*p - k) // s + 1
    W_out = (W_in + 2*p - k) // s + 1

    Y = np.zeros((C_out, H_out, W_out))
    for c in range(C_out):
        for i in range(H_out):
            for j in range(W_out):
                X_block = X_pad[:, i*s : i*s + k, j*s : j*s + k]
                Y[c, i, j] = np.sum(K[c, :, :, :] * X_block) + bias[c]
    return Y

def maxpool2d(X: np.ndarray, k=2, stride=2) -> np.ndarray:
    C, H, W = X.shape
    H_out = (H - k) // stride + 1
    W_out = (W - k) // stride + 1
    Y = np.zeros((C, H_out, W_out))
    for i in range(H_out):
        for j in range(W_out):
            block = X[:, i*stride:i*stride+k, j*stride:j*stride+k]
            Y[:, i, j] = np.max(block, axis=(1, 2))
    return Y

# ---- 测试：复现一个 VGG-like block ----
if __name__ == "__main__":
    X = np.random.randn(3, 8, 8)
    K = np.random.randn(8, 3, 3, 3)
    b = np.zeros(8)
    Y = conv2d(X, K, b, padding=1)
    P = maxpool2d(Y, k=2, stride=2)
    print("输入 X.shape:", X.shape)
    print("卷积后 Y.shape:", Y.shape)
    print("池化后 P.shape:", P.shape)
★ 本章要点 · KEY POINTS
  • 卷积层通过局部连接与参数共享，显著降低参数量同时保持空间结构信息；
  • 输出尺寸 = $\lfloor (H_{\text{in}} + 2p - k)/s \rfloor + 1$，这是设计网络必须掌握的基本公式；
  • 池化提供平移不变性与降采样，stride 卷积是其现代替代；
  • 残差连接让超深网络的训练成为可能，是 ResNet 及其后继结构的核心；
  • 理解经典架构的演进：LeNet $\to$ AlexNet $\to$ VGG $\to$ GoogLeNet $\to$ ResNet $\to$ EfficientNet/ConvNeXt。
